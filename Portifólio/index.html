Corrida Pixelada

Este é um jogo de corrida divertido e interativo desenvolvido com a biblioteca P5.js, como parte dos estudos realizados através das aulas da plataforma Alura. Diferente dos jogos de corrida tradicionais com carros e pistas complexas, este projeto traz uma proposta criativa e leve: os jogadores controlam emojis que "correm" na tela, e o vencedor é aquele que consegue pressionar as teclas corretas mais rapidamente.

O jogo permite a participação de até 4 jogadores, cada um representado por um emoji diferente. Durante a corrida, o sistema exibe teclas (A, S, D, W) que devem ser pressionadas em sequência. Cada acerto movimenta o emoji do jogador para frente, criando uma competição dinâmica baseada em agilidade e atenção.

Além da lógica de controle dos personagens e detecção de teclas, o jogo também conta com animações simples, criando uma experiência visual divertida. O uso de emojis como corredores traz um toque descontraído e acessível, tornando o jogo fácil de entender e ideal para jogar com amigos.

Esse projeto reforça conceitos fundamentais de programação interativa com JavaScript, como controle de eventos, manipulação de elementos gráficos e lógica condicional. É um excelente exemplo de como é possível criar experiências envolventes com ideias simples e código limpo.

Qual o Filme?

Este projeto é um recomendador de filmes interativo, desenvolvido com a biblioteca P5.js como parte dos estudos realizados por meio dos cursos da plataforma Alura. O objetivo do projeto é proporcionar uma experiência simples e personalizada, onde o usuário recebe sugestões de filmes com base em sua idade e preferências pessoais.

A interface do sistema conta com uma aba interativa onde o usuário informa sua faixa etária e seleciona seus gêneros favoritos, como drama, comédia, terror e animação. A partir dessas informações, o programa utiliza uma lógica de filtragem para exibir filmes que combinem com o perfil informado, criando uma experiência mais direcionada e eficiente.

Apesar de simples, o projeto aplica conceitos fundamentais da programação com JavaScript e P5.js, como entrada de dados, estrutura condicional, organização de listas e exibição dinâmica de conteúdo na tela. Além disso, o uso de uma interface amigável e intuitiva permite que usuários de qualquer idade possam utilizar o sistema com facilidade.

Este projeto também demonstra como é possível utilizar a programação para resolver problemas do cotidiano — neste caso, a clássica dúvida: “Que filme assistir hoje?”. Ao mesmo tempo, serve como exercício prático para consolidar conhecimentos em lógica de programação e desenvolvimento interativo.

Pixel Pong

Este projeto é uma versão digital do clássico jogo de ping pong, desenvolvido com a biblioteca P5.js como parte dos estudos realizados através dos cursos da plataforma Alura. O objetivo foi recriar de forma simples, porém divertida, um jogo nostálgico que funciona diretamente no navegador, utilizando os principais conceitos de programação gráfica e interatividade.

O jogo foi projetado para duas pessoas jogarem simultaneamente, cada uma controlando sua própria raquete com teclas específicas do teclado. A mecânica é simples: manter a bolinha em movimento e tentar fazer com que o oponente não consiga rebater, somando pontos a cada erro do adversário. O placar é exibido em tempo real, atualizando automaticamente a cada rodada.

Além da jogabilidade funcional, o projeto também conta com trilha sonora, que torna a experiência mais imersiva e dinâmica. Sons de impacto e fundo musical foram inseridos para acompanhar a ação e dar mais vida ao jogo.

Durante o desenvolvimento, foram aplicados conceitos como detecção de colisões, movimentação de objetos, controle de entrada de teclado, lógica de pontuação e efeitos sonoros. O projeto é uma ótima forma de praticar programação de jogos simples e entender como pequenas interações podem criar experiências engajantes.
